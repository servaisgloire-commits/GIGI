SQL & requêtes métier

Bibliothèque de requêtes prêtes pour le reporting, le contrôle de gestion et les analyses opérationnelles.

PostgreSQL

Reporting courses

Analyse des 90 derniers jours par pays, statut et prix.

SELECT created_at, country_code, status, estimated_price, final_price FROM public.rides WHERE created_at >= CURRENT_DATE - INTERVAL '90 days';

Chiffre d’affaires

Agrégation des paiements réellement encaissés par devise.

SELECT currency, COUNT(*) AS transactions, SUM(amount) AS chiffre_affaires FROM public.payments WHERE status = 'paid' GROUP BY currency;

Performance chauffeurs

Répartition des chauffeurs par statut et niveau de validation.

SELECT status, is_verified, COUNT(*) AS chauffeurs FROM public.driver_profiles GROUP BY status, is_verified;
